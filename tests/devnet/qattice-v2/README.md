# Qattice signing-v2 four-node integration fixture (disposable)

`genesis-4node-qattice-v2.json` is a **new** genesis for the disposable `four_node_signing_v2_live` test. It is the supported ML-DSA
devnet genesis (`../genesis-4node-mldsa.json`, left untouched) with: a fresh `chain_id` / `network_id`
(`qattice-v2-itest-4node`), `"commitment_profile": "qattice-v2"`, no settlement operators, and only the four validator accounts.

The test appends, at run time and in a temp copy, disposable user accounts (keys generated by the test, deleted afterwards), a
settlement operator and the `treasury:pocd-research` account. Validators use the **public test keys** in `../keys/mldsa/`.
**Never use any of these keys on a network anyone relies on. This is not the public-alpha genesis.**
